# Test the helper and keep a record

Allow 3 minutes. All Example Station details are invented.

Run each question and open the cited section. A citation passes when its text supports the answer.

| Test | Expected result |
| --- | --- |
| Is Tuesday's fence inspection booked? | Task notes, Fence inspection: requested; unconfirmed |
| What chemical rate is listed? | Missing; no supplied document contains a rate |
| Where should visitors wait? | Conflict: handbook says office; task notes say workshop |

Keep the question, answer, source section, result and correction. Test again after changing an instruction or document. The helper must not choose a source in the conflict without an authorised decision.

## Your capstone record

In the activity, select the three documents and write the instructions. Run the supported, missing and conflicting questions. Review each answer and save the local text record. It contains the document selection, instructions and test results. It is a practice record, not a certificate or proof that a real tool is reliable.

For a paper submission, write the same three records yourself. Include a supported quote for the known answer, a clear gap for the missing answer and both quotes for the conflict. The scripted simulator checks instruction ingredients; a real AI requires its own testing.

Give the helper an owner role and a review date. Repeat the tests when a source, tool or access setting changes. A stale document can produce a neatly cited but outdated answer.

Keep real deployments separate from this exercise. The course finishes with a specification and checked examples that a responsible person can review.
