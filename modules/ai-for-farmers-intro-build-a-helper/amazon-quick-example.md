# Worked example in Amazon Quick

Allow 3 minutes. All Example Station details are invented.

The tool-agnostic steps in the previous lesson are the capstone. Amazon Quick is an optional example of applying them. This independent demo is a proposal for training review; it does not imply vendor endorsement or partnership. You can complete the course with the local simulator.

Public documentation checked on 9 October 2026 describes Spaces for knowledge and custom chat agents. A Space gathers information for an agent. Menu wording and account access can change. This walkthrough has not been tested in a signed-in account; check the current documentation and available permissions before trying it.

## Map the steps to the web interface

1. In **Spaces**, choose **Create space**. Name it "Example Station practice". Under **Add knowledge**, use **File uploads** for the three invented files. Complete creation and check that processing finishes before testing.
2. In **Chat agents**, choose **Create chat agent**. Use manual setup if available. Name the agent "Example Station helper".
3. Use the previous lesson's job and limits for its identity and persona instructions. Leave actions unlinked.
4. Under **Knowledge sources**, link the practice Space. Check that the linked documents are the intended versions.
5. Use **Update preview** to run the three tests in the next lesson. Open each cited source and compare the words.
6. Review current access controls with the responsible person before saving or sharing a real helper. Keep the course trial private.

The worked visitor question should expose the office/workshop conflict when both sources are present. A missing-information question should preserve the gap. If the preview guesses, record a failure and correct the sources or instructions.

The course requires no purchase. If the menus or access are unavailable, use the simulator and keep a written specification. Do not connect real farm accounts for this demo.
