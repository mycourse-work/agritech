## If something is broken or unsafe

1. Take the key off the key board in the implement shed.
2. Hang the red "Do not use" tag on its hook instead.
3. Tell Jack, and write the fault on the list inside the implement shed door.

Don't try to fix a machine you haven't been trained on.
