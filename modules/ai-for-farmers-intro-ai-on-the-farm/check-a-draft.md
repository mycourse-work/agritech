# Check the answer before using it

Allow 3 minutes to read, then try the short activity. All Example Station details are invented.

Example Station's original note says "Tuesday requested; not confirmed". The AI draft says "Tuesday confirmed". Reject that change even if the rest reads well.

Use this check on every draft:

1. Compare names, dates, quantities and commitments with the input.
2. Recalculate any number that affects the job.
3. Open cited sources. Check the page, date, NZ relevance and the words that support the answer.
4. Mark missing information as unknown.
5. Decide who must approve the result before it is used.

A second AI answer is another draft. Agreement between two answers is not evidence from a label, a record or a current rule.

## Make a correction

Tell the helper: "Tuesday is a request. Remove the booking confirmation and the invented time." Check the revised version again. Keep the original note so you can explain the change.

For a no-account exercise, cross out the unsupported phrase and write a replacement sentence. This checks the same skill.
