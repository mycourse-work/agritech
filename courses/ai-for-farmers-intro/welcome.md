# Introduction to AI for Farmers

Use AI to draft a farm message, check a number and specify a small document helper. Start with the short video, read the phone lessons, try the activity and complete the scenario quiz. Each module also has a two-voice listening script for tractor time. Do screen activities when parked.

All Example Station material is invented. The four activities run locally and require no AI account. Paper alternatives are supplied. Each module video has English captions, and its page includes a text summary and the full narration script.

Allow about 86 minutes for the core course, plus optional listening. Your capstone is a helper specification and three checked test records. An 80% quiz threshold is a course setting, not a professional qualification.
